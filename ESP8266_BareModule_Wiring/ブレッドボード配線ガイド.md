# ESP-WROOM-02 (技適対応) ブレッドボード配線ガイド ― 秋月 DIP化キット使用

海外で広く流通している ESP-12E / ESP-12F 系の ESP8266 モジュールは日本の技適 (技術基準適合証明) を取得していないことが多く、日本国内で電波を出して使うなら **Espressif 純正の技適認証モジュール「ESP-WROOM-02」** を選ぶ必要があります。本ガイドでは、秋月電子通商の `ESP-WROOM-02 DIP化キット` (AE-ESP-WROOM-02) を前提に、ブレッドボードで仮配線して動かすところまでを解説します。

---

## 0. 技適 (技術基準適合証明) について

日本では、Wi-Fi/Bluetooth など電波を出す機器は **電波法に基づく技術基準適合証明** (略して「技適」) を取った機器でなければ、業務・実験を含めて使用すると違法 (電波法第4条) になります。

- **ESP-WROOM-02**: 技適認証あり (Espressif Systems / 認証番号: `R 201-160606`)。モジュールの金属シールド面に技適マーク (〒みたいなマーク) と番号が印刷されている。**日本で正式に使える ESP8266 モジュール**
- **ESP-12E / ESP-12F**: 一般的に技適認証なし。海外通販の ESP8266 開発ボードに搭載されているモジュールはこの系統が大半で、**日本国内で電波を出すと違法**
- **ESP-WROOM-32**: ESP32 系。これも技適認証あり (一部製品)。Wi-Fi+BLE 両対応

ブログにアップする工程では「**技適マーク付きの ESP-WROOM-02 を使うこと**」を明記しておくと、読者が違法状態に陥るのを防げます。

> 例外として「総務省への実験申請を出した上で 180 日まで」「電波暗箱内での試験」など、限定的に非技適機器を使える条文もあります (電波法施行規則 第6条等)。ただし通常の自宅 Wi-Fi 環境で使うのは **明確に違法** なので、本シリーズでは 技適済みの ESP-WROOM-02 一択で進めます。

## 1. 秋月電子 ESP-WROOM-02 DIP化キット の概要

| 項目 | 内容 |
|---|---|
| 製品名 | AE-ESP-WROOM-02 (DIP化キット) |
| 内容物 | ESP-WROOM-02 モジュール + 2.54mm ピッチ変換基板 + ピンヘッダ + 一部のチップ部品 |
| ピッチ | **2.54mm DIP** (普通のブレッドボードに刺さる) |
| 技適 | あり (R 201-160606) |
| Flash | 4MB (32Mbit) |

**この DIP 化キットで「すでに済んでいる」こと:**

- 1.5mm ピッチ → 2.54mm ピッチへの変換 (= ブレッドボードに直に刺せる)
- **EN (CH_PD) ピンの 10kΩ プルアップ** が基板上に実装済み (秋月版は標準で実装。製品ロットにより異なる可能性あるので添付説明書で確認)

**この DIP 化キットでも「自分で用意するもの」:**

- 3.3V 電源回路 (LDO + デカップリング)
- USB-Serial 変換アダプタ
- リセット / フラッシュ用ボタン
- GPIO15 プルダウン抵抗 (これが無いと起動しない)
- GPIO0 プルアップ抵抗 (これが無いと書き込みモードと通常モードを切替えられない)
- RST プルアップ抵抗

つまり「ピッチ変換は終わっているが、起動回路と書き込み回路は自分で組む」のがこのキットの位置付けです。**USB-Serial 変換アダプタや 3.3V 電源回路を別途用意しないと動きません。**

> 同じ秋月でも `ESP-WROOM-02 開発ボード` (AE-ESP-WROOM-02-DEV) は USB-Serial・LDO・リセット&フラッシュボタンを全部基板上に持っており、こちらは USB ケーブル一本で書き込みできます。本ガイドは **DIP化キット (素のキット) 版** です。

## 2. ESP-WROOM-02 のピン配置 (DIP化キット側)

秋月の DIP 化キットでは下記ピンが 2.54mm DIP として引き出されます。番号はキットのシルク印字の例です (実物のピン配列を必ず確認してください)。

```
                 ┌──────────────────────┐
            3V3 ─┤                       ├─ EN (内部で 10kΩ プルアップ済み)
             IO14 ─┤                     ├─ IO16
             IO12 ─┤  ESP-WROOM-02       ├─ IO13
             IO15 ─┤  DIP化キット         ├─ IO5
              GND ─┤  (秋月 AE-WROOM-02) ├─ IO4
              IO2 ─┤                     ├─ RST
              IO0 ─┤                     ├─ TOUT (ADC, 最大 1.0V)
              GND ─┤                     ├─ IO9 ※未接続/使用禁止
              RXD ─┤                     ├─ IO10 ※未接続/使用禁止
              TXD ─┤                     ├─ 3V3
                 └──────────────────────┘
```

- `IO9` / `IO10` (= GPIO9, GPIO10) は **使わないこと**。内蔵フラッシュとの通信に予約されており、配線するとフラッシュアクセスを壊す可能性があります。
- `IO6 〜 IO11` も内蔵フラッシュ用なので一切引き出されていません。
- 使えるのは `IO0, 2, 4, 5, 12, 13, 14, 15, 16` の 9 本。

## 3. 起動するために必要な抵抗 (ストラッピングピン)

ESP-WROOM-02 でも内部チップは ESP8266EX なので、起動条件は ESP-12E と同じです。

| ピン | 起動時に必要な状態 | 抵抗 | DIP化キットに内蔵? |
|---|---|---|---|
| **EN** | HIGH | 10kΩ プルアップ → 3V3 | **YES** (秋月版は実装済み) |
| **IO15 (GPIO15)** | LOW | 10kΩ プルダウン → GND | NO (自分で配線) |
| **IO0 (GPIO0)** | HIGH (通常起動) / LOW (書き込み) | 10kΩ プルアップ → 3V3 | NO (自分で配線) |
| **IO2 (GPIO2)** | HIGH | 内蔵プルアップあり (外付けは DS18B20 4.7kΩ で兼用) | -- |
| **RST** | HIGH | 10kΩ プルアップ → 3V3 | NO (自分で配線) |

> EN プルアップが基板上で実装済みかどうかは、キット添付の組立説明書または基板シルクで必ず確認してください。実装済みでも「外付けでさらに 10kΩ を並列に入れる」のは害にはなりません。

## 4. 電源回路

ESP-WROOM-02 は Wi-Fi 送信ピーク時に **瞬間的に 250〜400mA** 流れます。**Arduino UNO の 3.3V 出力 (~50mA) からは絶対に給電しないこと**。Wi-Fi 接続の瞬間にブラウンアウトでリブートが続発します。

### 推奨回路 (5V → 3.3V LDO)

```
5V (USB等) ──┬── [ AMS1117-3.3 ]────┬── 3.3V レール
             │   IN          OUT     │
            10µF                    10µF        ← 入出力に大容量コンデンサ
             │   GND                 │
             └────┬──────────────────┘
                  │
                 GND

   3.3V レール ──┬── (ESP-WROOM-02 の 3V3 ピン)
                 │
              100nF (セラミック) ← VCC ピン直近に必ず配置
                 │
                GND
```

- AMS1117-3.3 は安価だが効率が悪い (LDO 方式で発熱)。1A 出力品を選ぶ
- DC-DC モジュール (例: HT7833 / ME6211 / Pololu などの 5V→3.3V) を使うと発熱が小さく安定
- **100nF (0.1µF) のセラミックコンデンサを ESP-WROOM-02 の 3V3 ピンの真横に**。突発電流による電圧降下を吸収する
- 入力 10µF / 出力 10µF (タンタル or 電解。電解の場合は極性に注意)

### 電源 NG パターン

- Arduino UNO の 3V3 端子からの給電 → 容量不足
- 9V 電池 + 7805 + AMS1117 → 効率最悪、電池すぐ切れる
- 細い USB ケーブル → 電圧降下でブラウンアウト

## 5. USB-Serial 変換アダプタ (書き込み用)

| 推奨チップ | 備考 |
|---|---|
| **CP2102 / CP2104** | ドライバ安定。**3.3V/5V 切替ジャンパを必ず 3.3V 側に** |
| CH340G / CH340C | 安価。Win/Mac はドライバを別途インストール |
| FT232RL | 高品質だが高価。偽物注意 |

**重要**: ESP-WROOM-02 は 3.3V 系。アダプタの TX/RX が 5V ロジックだと壊れる可能性があります。3.3V/5V ジャンパを確認してから接続してください。

### 配線

```
USB-Serial アダプタ          ESP-WROOM-02 DIP化キット
─────────────────            ──────────────────────
GND  ──────────────────────── GND
TXD  ──────────────────────── RXD
RXD  ──────────────────────── TXD
3V3  ──── (補助給電に使う場合のみ。容量に注意) ─── 3V3
```

**TX↔RX はクロス**します (アダプタの TX → ESP の RX)。書き込みできない時はまずここを疑う。

## 6. リセット & フラッシュ用ボタン

```
3V3 ──[ 10kΩ ]──┬── RST ───┐
                 │            │
                 └─[SW1: RESET]── GND

3V3 ──[ 10kΩ ]──┬── IO0 ───┐
                 │            │
                 └─[SW2: FLASH]─ GND
```

**書き込み手順:**

1. SW2 (FLASH) を押し続ける
2. SW1 (RESET) を押して離す
3. SW2 (FLASH) を離す
4. → ESP は UART 書き込みモード
5. Arduino IDE から書き込み実行
6. 書き込み完了後、SW1 (RESET) で通常起動

> CP2102 / FTDI などの DTR/RTS を ESP の RST/IO0 に専用回路で繋げば自動書き込みにできますが、最初は手動で OK。

## 7. DS18B20 の追加配線

```
3V3 ──┬───────────── DS18B20 VCC
       │
     [4.7kΩ]
       │
       ├───────────── DS18B20 DATA ──── ESP-WROOM-02 IO2 (GPIO2)
       │
       (= GPIO2 の HIGH 確保も兼ねる)

GND ───────────────── DS18B20 GND
```

**ポイント:** この 4.7kΩ プルアップは「DS18B20 の 1-Wire プルアップ」と「ESP8266 GPIO2 のストラッピング (HIGH) 確保」を兼用。

## 8. 全体配線図 (最小構成)

```
 ┌──────────────[ AMS1117-3.3 ]──────────────────┐
 │5V─IN  GND  OUT─3V3 レール                       │
 │     ├10µF─GND   ├10µF─GND                      │
 └──────┴──────────┴──────────────────────────────┘

 3V3 レール ──┬─── (ESP-WROOM-02 3V3 ピン)
              │
           100nF (3V3 ピンの真横)
              │
             GND

 [ESP-WROOM-02 DIP化キット]

 EN ←(基板内蔵 10kΩ で 3V3 にプルアップ済み)

 RST ──[10kΩ]── 3V3
   └──[SW1: RESET]── GND

 IO0 ──[10kΩ]── 3V3
   └──[SW2: FLASH]── GND

 IO15 ──[10kΩ]── GND   ← プルダウン (向き注意)

 IO2  ── DS18B20 DATA ─┬─[4.7kΩ]── 3V3
                       │
                       └── DS18B20 DATA ピン
 DS18B20 VCC → 3V3
 DS18B20 GND → GND

 USB-Serial アダプタ (3.3V):
   TXD ──→ RXD (ESP)
   RXD ──← TXD (ESP)
   GND ──── GND 共通
```

## 10. Arduino IDE のボード設定

ESP-WROOM-02 単体には **Generic ESP8266 Module** を選ぶのが自然です。

| 項目 | 設定値 |
|---|---|
| ボード | **Generic ESP8266 Module** |
| Builtin LED | 2 |
| Upload Speed | 115200 (慣れるまで) / 安定したら 460800 |
| CPU Frequency | 80 MHz |
| Crystal Frequency | 26 MHz |
| **Flash Size** | **4MB (FS:2MB OTA:~1019KB)** ※ ESP-WROOM-02 は 4MB |
| **Flash Mode** | **DOUT** (互換性最優先) |
| **Reset Method** | **"no dtr (aka ck)"** (手動 RESET/FLASH ボタン運用) |
| Flash Frequency | 40 MHz |
| Erase Flash | 普段 "Only Sketch"、初回や挙動不審時は "All Flash Contents" |

> **注意:** "Generic ESP8266 Module" を選ぶと `D4` のようなピン別名記号は使えません。スケッチでは GPIO 番号 (例: `4`) を直接書く必要があります。本シリーズの STEP 1 / STEP 2 のスケッチはこの前提で書いてあります。

## 11. 動作確認の順番

ハマった時は以下の順で確認すると切り分けが早いです。

1. **3V3 レールをテスタで実測** — 3.25〜3.35V か、Wi-Fi 送信中も大きく落ちないか
2. **EN ピンを実測** — 3.3V 近辺か (LOW なら DIP化キットの EN プルアップが壊れている / 不実装)
3. **IO15 を実測** — GND 近辺か (HIGH なら 10kΩ の向きが逆 / 配線忘れ)
4. **IO0 を実測** — 通常時は 3.3V、SW2 押下時は 0V
5. **RST を実測** — 通常時は 3.3V、SW1 押下時は 0V
6. **シリアルモニタを 74880 baud で開く** — ESP8266 は起動時にこの妙な速度でブートメッセージを吐く。これが見えれば「電源と TX が生きている」
7. **115200 baud で `Serial.begin(115200)` のスケッチ出力を確認**

## 12. よくあるトラブル

| 症状 | 原因 | 対処 |
|---|---|---|
| 通電しても何も起きない | EN または IO15 のストラップ未配線 | 抵抗を再確認。EN は DIP化キット内蔵なので IO15 を疑う |
| Wi-Fi 接続のたびに再起動する | 電源容量・デカップリング不足 | 100nF を VCC 直近に追加。LDO を 1A 品 / DC-DC に変える |
| `espcomm_open failed` / `error: Failed to connect` | フラッシュモードに入っていない | SW2押→SW1押離→SW2離 の順序確認、TX↔RX クロス確認 |
| 書き込み中に `head packet error` | Flash Mode 不一致 | DOUT ⇄ DIO を切替えて再試行 |
| 文字化け | ボーレート違い | シリアルモニタを 115200 に |
| `'D4' was not declared in this scope` | ボードが Generic ESP8266 Module の時にピン別名記号 (`D4` 等) を使った | スケッチで GPIO 番号 (`4` 等) を直接書く |
| `-127 ℃` ばかり返る | DS18B20 のプルアップ未配線 | 4.7kΩ を 3V3 と DATA 間に |
| ボード上の青LEDが点滅し続けて起動しない | IO0 がプルアップされていない (= 常時書き込みモード) | IO0 → 3V3 への 10kΩ プルアップを再確認 |
| 通信が断続的に切れる | 電源ノイズ・配線が長すぎる | 配線を短く。電源系を見直す |
